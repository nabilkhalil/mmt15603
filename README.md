## Adding a deck

1. Put the `.html` file in `slides/`.
2. Commit and push. The home page lists every file in `slides/` automatically; GitHub Pages updates in a minute or two.

Interactive lathe figures are built with the [Anatomy](https://github.com/wheresryan22/anatomy) kit (MIT).
